# 战雷低压力陪伴提示词

2026-11-01。目标：保留当前角色的猫猫个性，让战斗播报提供信息与陪伴，减少责备、催促和战绩压力。只调整插件提示词、事件要求、风格元数据及直出短句，不修改宿主人设或全局 system prompt。

## 行为边界

- 不嘲讽操作、反应、战绩或载具选择，不使用侮辱性称呼；即使当前人设傲娇，也不把毒舌和嫌弃对准玩家。
- 不责怪玩家，不攀比、不催连杀或翻盘、不激将；不归罪队友、不煽动争吵，也不猜玩家情绪或命令其冷静。
- 阵亡和失利后只确认事实，简短陪伴，不评价操作、不擅自复盘、不追问原因。交换战果不评价得失，未知胜负不猜。
- 击杀后自然确认或分享开心，鼓励保持克制，不强行积极，也不要求继续证明自己。
- 普通提醒平静说；紧急提醒先说清危险和动作，不渲染灾难，不为柔和语气省略必要动作。
- 继续一句中文、28 字内、不反问、不续聊；四域词汇、事实白名单、未知边界和聊天避让沿用现有规则。

## 实现位置与表达示例

`core/instructions.py` 的常驻战雷上下文增加上述边界；`adapters/neko_dispatcher.py` 的每条事件要求也带有“不责怪、不嘲讽、不催战绩”，避免只依赖常驻上下文。英文风格元数据同步为 calm, non-judgmental；移除“插件不指定情绪或措辞”的无边界表述，措辞仍由当前角色决定。

| 场景 | 调整后方向或直出短句 |
|---|---|
| 阵亡 | 陪伴一句，不评价操作、不擅自复盘；不设置固定安慰台词 |
| 击杀/交换 | 自然回应可信战果，不催下一次击杀、不评价交换划不划算 |
| 低空危险 | “离地过低，立即拉起！”替换“拉起来，要撞地了！” |
| 炮手失能 | “炮手失能，留意掩护。”替换“炮手没了，先别硬拼！” |
| 一级待发弹打空 | “一级弹药已空，留意装填。”替换“一级弹药空了，别硬拼！” |

表中的直出短句只在既有配置允许的路径使用；常规 LLM 回复仍由当前角色生成。这些示例不是实际模型输出或试听结果。
