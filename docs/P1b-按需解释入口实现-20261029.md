# P1b 会话按需解释入口

日期：2026-10-29。用户选择 [评审推荐 B 与 D1–D5](P1b-按需解释接入评审-20261029.md)，本期已实现、review、离线验证并备份同步实际宿主。默认关闭；没有运行供应商模型、TTS、实际游戏或原生 Electron。没有重建 RC、重跑整套 preflight/release-readiness、commit、push 或发布；原先跳过的现场验收仍未验收，不阻塞后续研发。

## 使用与会话边界

设置 → **按需解释（本次会话）** → **本次会话启用并绑定当前角色**。启用前提示定义/结果增加 token，普通回答可能依宿主聊天设置发声，战斗 dry-run/暂停不等于普通问答静音。启用并不证明主服务、模型端工具列表或实际调用已确认，面板先显示“已请求注册”，收到实际调用才显示调用状态。

只注册一个 `warthunder_get_current_facts_<会话随机后缀>`；同一入口仅接收 `view=status / capabilities / output_policy`，拒绝多余字段、自由文本、角色参数和 `_ctx`。角色 scope 固定，`reply_tail=false`，未知角色不使用全局注册。切换角色后查询拒绝并要求重新绑定；重新绑定先让旧 handler 失效，再注销、注册新名称，旧名字/闭包不能读取新绑定。停用先本地拒绝，再尽力清理；重启不恢复，开关不写配置或状态文件。旧 SDK 没有注册能力、角色不可确认和注册/清理异常时退回现有面板，异常文本不返回。

当前角色从宿主 runtime `characters.json` 的有效“当前猫娘”选择只读重取，使用既有配置路径定位、禁止迁移/修复写回，不使用上次调用角色/玩家名/模型参数/全角色 fallback；单次读取上限 2 MiB，缺失、格式错误、无效或超限关闭入口。角色 scope 和该文件检查不是调用者强身份认证，无法证明用户意图或真实用户轮次。停用后残留 schema 和对话历史不保证即时消失；SDK 停止链路还依赖宿主原有 registry clear。

## 事实与真实输出

[适配器](../adapters/on_demand_explanation.py) 经 [插件入口](../__init__.py) 复用 P1a `trusted_facts`；[面板](../ui/panel.tsx) 只维护会话开关和状态。每次查询重新投影，不重复采样、不推进/重置检测、不改生命/候选/播报配置，不调用 Dispatcher/push_message/模型，也不缓存上一结果。未新增依赖、遥测轮询、常驻服务或摘要持久化。

| 视图 | 可返回内容 | 边界 |
|---|---|---|
| status | 域、当前可用状态、白名单至多五项事实、来源年龄/生命绑定说明 | P1a 的未知/过期/回放/阵亡/断线/切域/新生命边界原样保留；舰艇只地图观察 |
| capabilities | 现有能力及来源/限制代码 | 有能力不等于检测命中或真实输出授权 |
| output_policy | 当前 dry-run/暂停及已有开关策略 | 固定声明 current_policy_only_not_event_cause，不能还原特定历史未播原因 |

不暴露身份、原始 chat/HUD/combat/payload、完整 flags、battle/life id、异常堆栈、URL/本地路径、舰艇未验仪表/静态生效参数或活动历史。特定事件仍转现有活动页对照。乘员/弹药、受限 V2、VRS、两类海战事件及 free-text 原输出边界均未改变。工具结果可进入宿主对话历史；之后问“现在”须重新读取，旧历史不自动删除。

## 预算与限流

| 项目 | 已实现约束与本次测量 |
|---|---|
| 默认关闭 | 不注册 schema、不查询、不主动注入；启用后的定义常驻/历史重发仍会产生成本 |
| 参数 | 严格单 view 枚举，序列化 ≤128 UTF-8 bytes，离线代理目标 ≤32 tokens |
| 结果 | 运行时 ≤1200 UTF-8 bytes，超额整字段未知降级，不截断 JSON/单位/限制；固定短错误无原输入回显 |
| 频率 | 插件全局 5 秒冷却、并发 1、忙时固定码、无自动重试；重绑不重置冷却 |
| 超时 | SDK 2 秒，handler 返回前复查用时/角色/会话代次；异步动态入口让停用可使迟到结果失效 |
| 离线 token | 本地缓存 o200k_base：示例定义 109、固定说明 44；157 合成状态 × 三视图 = 471 样例，最高 228 tokens / 844 bytes，均在 160/80/320 代理目标内 |
| 暖态耗时 | 400 次实际投影+角色文件读取+异步 handler，p95 2.81 ms，目标 ≤50 ms；不含 IPC/网络/模型/TTS |
| 最终回复 | 工具描述要求用户明确问时调用一次，建议 1–3 句；不是可验证用户轮次或最终回复/TTS 硬 token 限额 |

测量报告见 [budget-report](../../archive/on-demand-20261029/budget-report.json)。代理计数不是供应商账单或跨 tokenizer 硬上限；实际成本还包括定义/参数/结果、provider framing、原对话/历史重发和继续生成的回答/推理/音频。限流只能限制读取，不能阻止模型持续尝试产生 token。
