# v0.1.2 版本范围与验收边界

此版本汇总此前尚未发布的四域副驾驶增量、遥测可靠性修复及低压力陪伴提示词。版本号在 plugin.toml、pyproject.toml、uv.lock 中一致；正式发布状态以 [GitHub Release](https://github.com/CN-Zephyr/n.e.k.o_plugin_neko_warthunder/releases/tag/v0.1.2) 和插件市场记录为准。

## 体验变化

- 低压力陪伴：保留角色个性，明确不责怪、不嘲讽、不催战绩；阵亡后不评价操作、不擅自复盘，紧急提醒仍清楚传达必要动作。
- 出生与生命边界：等待真实载具，短暂遥测中断恢复不重复报出生，进场事件不再声称已经升空、起飞或移动。
- 聊天避让：通过公开 SDK get/dump 读取当前角色的活动，兼容旧记录封装；文字和语音继续遵循既有静默窗与打断策略。
- 四域只读概览：展示有界事实、来源时效、可用能力及输出限制，未知和过期数据不当作当前读数。
- 陆战：乘员、一级待发弹、岗位与激光告警状态卡；一级待发弹说明区分当前数量、数据标记与输出，不等同全车余弹。
- 直升机：旋翼转速、离地高度和升降速度只读卡，VRS 风险仅检测记录。
- 海战：保守域识别、地图只读卡、dry-run 检测进度与结果对照、独立采样字段证据，以及固定提交的 Datamine 静态声明与改装解析；不把静态配置当作实时或当前生效参数。
- 空战诊断：显式 state 油温通道只读展示，燃油消耗估算增加时效、补给和重建基线保护。
- 支持同步自定义地图敌我颜色；颜色无法区分时保守降级。

## 默认行为

新安装保持 dry-run。按需解释默认关闭，需本次会话显式启用并绑定当前角色，只查询当前状态、可用能力和输出策略；有预算、冷却和并发限制。现有播报与聊天避让配置不因发布而自动开启。

陆战乘员/待发弹专项真实输出默认关闭；V2 未验证提醒沿用独立门控；直升机 VRS、海战图标专项事件及自由文本事件保持真实输出硬关闭。

## 已知限制

- 既有过热候选的温度归因仍待独立修复。此次新增的 state 油温只读诊断没有修复该告警归因。
- 此前 indicators/map_obj 的现场异常目前没有确定根因，不宣称本版修复上游接口异常。
- 实际角色对新提示词的遵循、TTS、Electron 及完整四域游戏现场序列尚未完成本版验收。
- 舰艇单位、物理语义、完整生命周期、当前改装与参数生效仍需证据；不开放相关仪表读数和专项播报。
- 用户已跳过的验收继续标为未验收，不作为研发阻塞，也不改记通过。
