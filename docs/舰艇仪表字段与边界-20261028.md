## 范围与成本

用户明确要求先梳理舰艇只读仪表可用字段和边界。本轮采用保守方案：只盘点已有 indicators 的 speed、heading_deg（原始 compass）、rpm、throttle；不猜舰艇专用键，不把通用/坦克/飞机数值直接变成舰艇读数。若延后，本阶段只有此前地图和检测诊断；完整仪表数值需要舰艇样本、语义及独立采样合同，未在本轮实现。

新增一个无状态纯投影模块和高级详情卡；每次读取固定四字段，无新增轮询、目标扫描、后台服务、依赖、配置、缓存/持久状态或 LLM/token 调用。运行改动为 adapters/naval_instrument_fields.py（新增）、__init__.py 和 ui/panel.tsx；不改检测、Scenario、Arbiter、Dispatcher、profile、数据层协议或输出政策。面板沿用已有简体中文界面，没有新增 i18n key。

## 已确认与缺口

源码能证明四项字段的解析/传输路径。定向扫描本地 8 个 indicators/processed 采样文件，未发现 ship/fleet 标记；这是有限本地证据，不证明游戏没有舰艇字段。

通用数值解析存在布尔/字符串转浮点行为，新投影对原始键额外执行严格有限非布尔校验；只规范化、只原始、缺失、非法、冲突分别说明，合法零与缺失分开。舰艇单位、符号、范围未验，因此不显示原始或规范化值，不转换航速/角度/控制量。

字段盘点依据当前基础响应及严格海战来源。响应 timestamp 与 fast age 用于收起过期响应，不宣称是独立成功仪表样本；生命标识只检查上下文，不能证明缓存仪表归属该生命。投影的 instrument_values_enabled、sample_life_bound、naval_semantics_verified、real_output_enabled 始终为 false。地图/vehicle 的采样数据不作替代证据。

只在高级详情显示，概览保留原有卡片。未知域相关上下文可查看来源未就绪说明；空/直升机/陆战不混入舰艇字段卡。投影只输出状态、固定 id 与有限响应年龄，无数值/单位、玩家身份、原始键值、聊天/HUD、完整 payload；读卡不改变 state、检测器、timeline、配置或输出。
