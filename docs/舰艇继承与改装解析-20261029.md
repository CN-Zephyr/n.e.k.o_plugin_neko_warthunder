## 固定来源与解析规则

全部来源固定于 Datamine 提交 `af0cce561a73704e30c1df66eff06209bcc3f035`，资料版本 `2.59.0.92`；没有验证本机游戏版本。

- [734 个舰艇目录配置](https://github.com/gszabi99/War-Thunder-Datamine/tree/af0cce561a73704e30c1df66eff06209bcc3f035/aces.vromfs.bin_u/gamedata/units/ships)：复用八期缓存，每次构建重新核对每文件 Git blob SHA 与长度。
- [公共改装定义](https://github.com/gszabi99/War-Thunder-Datamine/blob/af0cce561a73704e30c1df66eff06209bcc3f035/char.vromfs.bin_u/config/modifications.blkx)：885,801 字节，blob `5d17d9cde673a87dab0aa4e19ade7e5fbec49d80`，3,860 个公共定义和 `new_gun` 模板；不把所有公共定义视为某舰已安装。
- [游戏改装 UI 逻辑](https://github.com/gszabi99/War-Thunder-Datamine/blob/af0cce561a73704e30c1df66eff06209bcc3f035/gui.vromfs.bin_u/scripts/weaponry/modificationinfo.nut) 依赖 available/purchased/enabled、模式和原生 overdrive 查询；[模式配置](https://github.com/gszabi99/War-Thunder-Datamine/blob/af0cce561a73704e30c1df66eff06209bcc3f035/aces.vromfs.bin_u/config/gameparams.blkx) 含不同难度的 modificationsEffect/wholeModificationsEffect 等声明。据此判断：仅这两份静态声明不足以推算最终效果，原生顺序和算法仍未验证。

[离线解析器](../tools/naval_modification_resolution.py) 只处理单位已声明的 ID，不自动添加公共库中的其他改装。本地标量存在时记录本地候选，否则记录同名公共候选；非法本地值保持缺口，不悄悄回退公共值。这是声明取源规则，不冒充引擎实际覆盖/激活规则。

例如 Fletcher 的 new_ship_engine 公共 prevModification 为 new_ship_rudder，本地改成 new_ship_screw；分别记录候选与来源。manual_ship_extinguisher 的公共 disableModEffects 和本地 `{}` 同时保留，merge_status=not_simulated，不深合并出游戏实际停用效果。invertEnableLogic 只保存布尔声明，不假定乘数适用方向。

effects/disableModEffects 及 upgrade/overdrive 正向/反向块分别保留来源；嵌套数字/布尔原子只进入离线报告，每块最多 2,048 原子、12 层。字符串/数组/复杂块的未解释值和其他经济/UI/特殊声明键显式记录，不当作无效果。模板 ID 与 copyWeaponMod 仅追踪引用，不读取外部武器、模拟复制或做乘数叠加。**本批舰艇没有直接模板引用**，模板/缺失/循环/继承指令分支只有合成回归证据。
