## 范围与数据来源

| 显示内容 | 数据层来源 | 展示约束 |
|---|---|---|
| 旋翼转速 | `processed.rotor_rpm` → BattleState | 单位 rpm；非负有限数，零保持为零，不用转速推断故障 |
| 离地高度 AGL | 既有 `radio_altitude_m` 映射，优先 processed，缺失时兼容 indicators | 单位 m；非负有限数，不替换为海拔高度 |
| 升降速度 | `processed.vario_ms` → BattleState | 单位 m/s；有限数，负数表示下降 |

- 仅 `domain == "heli"` 显示，在概览和诊断高级详情使用同一组件。
- 缺失、非法、NaN/Inf 保持未知；不把未知当零。缺少采样 metadata 的旧数据兼容展示，但明确显示采样时间未知。
- 复用陆战卡片的载具采样年龄与状态降级：独立 `meta.vehicle.age_sec`，缓存读取继续计龄，超过 5 秒隐藏旧值；offline、waiting、dead、replay 或 vehicle invalid 同样隐藏仪表值。
- 不新增轮询、依赖、配置、持久状态、LLM 调用或 UI action；不注册 VRS / 转速 Detector，不修改 Scenario、Arbiter、Dispatcher 或输出开关。
