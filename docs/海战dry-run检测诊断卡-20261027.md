## 范围与成本

本轮按用户明确要求采用只读投影：复用现有成功地图采样、来源校验及两类 NavalContactDetector，不新增遥测轮询、目标扫描、后台服务、依赖、配置、持久状态或 LLM/token 调用。每个检测器仅增加一个固定大小的不可变进度快照，每次 feed 完成后发布；卡片读取执行常数级校验和投影。完整舰艇仪表/重生/安全输出需要另定范围，未在本轮实现。

运行修改限于 `__init__.py`、`core/telemetry_freshness.py`、`detectors/discrete/naval_situation.py` 和 `ui/panel.tsx`。不修改数据层合同、采样频率、两次独立采样/两次消失阈值、冷却、场景、优先级或仲裁/投递门控。前一期事件合同见 [态势事件记录](海战态势事件-dry-run-20261027.md)。

## 展示与只读边界

概览和诊断高级详情显示同一张卡；仅 naval 或带地图/战局的 unknown 域显示，固定翼/直升机/陆战不混入海战卡。

| 内容 | 当前含义 |
|---|---|
| 来源状态 | 直接复用实际检测谓词；有效海战兵种、在场且存活、非回放、已知战局/生命/成功采样、5 秒内来源、自身位置及合法聚合数量才 ready |
| 来源年龄/序号 | 展示有限地图年龄与校验后的成功采样序号；断线、回放、等待进场、阵亡、未知海战、未知战局/采样、过期、旧生命、缺自身位置/坐标及非法计数分别说明 |
| 等待检测 0/2 | 当前采样键尚未有完成的检测更新；新战局/生命/采样回退不借用旧确认 |
| 出现确认 1/2 | 等待第二次独立成功样本；重复缓存、刷新卡片不累计 |
| 出现已确认 2/2 | 已产生本次出现候选，持续存在不重复；仲裁与记录结果看活动页，不表示已播报 |
| 消失确认 1/2 | 再取得一次有效消失采样才重新待命，不产生恢复/出现事件 |
| 未发现 0/2 / 来源未就绪 / 停用 | 分别解释没有此类图标、来源失效、插件暂停；失效时不展示旧进度 |
| 输出策略 | 永远显示真实输出关闭；全局 dry-run 关闭也不能开放两类事件，未增加操作按钮 |

读取不 feed、不 reset、不改 detector、原始遥测、配置、状态或仲裁时间。来源随读取时间降级，但检测状态只由原轮询推进。对并发半更新仅展示上一次完整快照；与当前采样不匹配则 pending。诊断子树仅输出原因码、布尔值、有限年龄、有效计数和两类事件进度，不输出玩家名、聊天/HUD、原始 payload 或战局标识。
