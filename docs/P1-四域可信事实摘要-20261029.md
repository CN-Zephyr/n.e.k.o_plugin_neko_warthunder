# P1a 四域可信事实摘要

日期：2026-10-29。范围来自 [总计划 P1a](实现计划-codex.md#下一轮开发范围)。本期完成只读事实摘要，不实现 P1b 对话问答，不改变真实输出策略。原 R2/R3/H/N 现场项继续“用户决定跳过、未验收”，不阻塞后续开发。

## 实现与边界

- `adapters/trusted_facts.py` 复用当前 dashboard 的 telemetry/ground_status/helicopter_status/naval_status/map_status；入口只增加 `trusted_facts`，概览复用原面板样式并可跳到既有活动页。保留原四域状态卡。
- 每份摘要最多五项事实、一项来源、三项能力与限制代码；只包含白名单数字/布尔/固定代码，不包含玩家名、chat/HUD/combat 原文、原始 payload、战局/生命标识、完整 flags 或静态配置值。
- 固定翼：指示空速、马赫、AGL、海拔、燃油比例。陆战：乘员/总员、一级待发弹、LWS、稳定器、档位。直升机：旋翼转速、AGL、升降速度。海战/未知：地图可见敌友/空中图标数、最近敌图标平面距离/绝对方位；未知域仅通用地图能力。
- 复用既有来源状态与独立年龄，同时复核 fast 时间与缓存读取计龄；5 秒失效、离线/等待/阵亡/回放、缺年龄/非法/未来时钟时收起值。未知、0、false、负升降速度/倒挡/无 LWS 设备保持区别，异常燃油范围/枚举不当作事实。
- 地图沿用已有 sample-life 校验。载具来源没有独立 sample-life 合同，明确标记 `life_binding=unverified`；不把响应 life 当成独立采样证明，不新增重生推断或跨读取缓存。旧卡缺年龄时的兼容显示保留，但新摘要收起未证实时效的值。
- 海战不借用空/陆/直升机残留字段，不开放舰艇仪表值、静态生效参数、舰员/弹药/进水/损伤或告警。地图可用与独立仪表探针失败分开处理。
- 输出区只反映既有暂停/dry-run/开关，不表示某事件已经获准或发声；乘员/弹药及受限 V2 默认关闭，VRS/两类海战事件硬禁播。摘要无 `test_say` 或其他业务 action，活动链接只切换本地页签。
- 无新增轮询/HTTP、后台模型、prompt 注入、依赖、配置或持久化；每次刷新仅投影少量固定行，不 feed/reset 检测、推进确认或改动队列。已有成本门禁继续有效。
