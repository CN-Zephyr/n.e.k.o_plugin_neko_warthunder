## v1.11 独立采样合同

在 `/api/telemetry.meta.naval_indicators`（健康检查 `groups.naval_indicators` 同结构）增加可选兼容元数据：

| 字段 | 合同 |
|---|---|
| status | ready，或有限原因码 unavailable/probe_failed/waiting/dead/replay/context_changed/invalid_source/unknown_life/unknown_age |
| count | 本战局已接受的成功观测编号，初始 0；只随成功采样增加，重复读面板/快照不增加，失败保留计数；离局重置 |
| sample_timestamp / age_sec | 请求开始的服务端墙钟时间（保守计龄上界）与经过年龄；非 ready 不保留 timestamp，age=null；消费者同时按当前时钟与上报年龄计龄，超过 5 秒隐藏旧字段 |
| battle_id / life_index / army | 仅 ready 携带，标记这次被接受采样的已确认战局/生命/兵种；不向诊断卡暴露标识原文 |

采样独立于 `meta.fast` 尝试编号、`vehicle` 和 `map_objects` 成功元数据，但**不是新增独立轮询线程**。复用既有 `/indicators` + `/map_info.json` 探针：两个请求均成功、确认在战、原始 valid 严格为 true、原始与规范化 army 一致为 ship/fleet，且在线存活非回放，才可能接受采样。即使 `/indicators` 成功，map_info 探针失败也保守拒绝，不能独自证明仍在同一战局；`/state` 或地图物体请求成功不是仪表成功的前置。

请求开始前记录内部 generation/battle/life/dead/replay/army 上下文；完成时持锁复核。进局首帧、确认重生帧、域变化或请求中发生上下文变化，都先撤掉绑定，下一次稳定成功请求才建立新绑定。请求失败在已有连接宽限期内也立即清除仪表可用证据，不沿用旧字段；离局清空计数与绑定。墙钟回退帧不接受。采样时间取请求开始而非整轮完成时间，慢 map_info/state 请求不能让更早的 indicators 数据变新；消费者按采样时间独立过期。这个绑定只跟随现有可信生命周期，仍无舰艇运动/舰员重生模型。

消费者对新元数据采用严格正整数、有限时间、原始身份与 battle/life/army 一致性检查。显式非法元数据或失败原因不回退为旧响应证据；旧 external 数据层**完全缺少该键**时保留 legacy_response，只盘点响应而明确 sample_life_bound=false。ready 仅表示来源样本归属，不表示四个字段都存在或有效，各字段仍分别可能缺失/非法/冲突。

## 只读面板与隐私

高级详情增加采样原因、成功序号与年龄。采样绑定可为 true，但 instrument_values_enabled、naval_semantics_verified、real_output_enabled 始终 false；不显示实际仪表读数、不触发检测、不写配置/状态，不改变 Detector/Arbiter/Dispatcher。失败、过期与旧战局/生命元数据下四项字段统一 unavailable；旧数据层只显示“生命绑定未知”。

手动审计命令（在插件 pyproject 所在目录）：

```powershell
uv run --offline python tools/naval_field_evidence.py --samples local_samples --out ../archive/naval-instrument-sampling-20261029/local-naval-evidence.json
```

工具只输出四项字段的状态计数、ship/fleet 标记数量、已消费内容前缀 SHA 和扫描完整性，不输出值、单位、玩家名、路径或 payload。超过单行 1 MiB 或总行数上限时标记 partial；部分摘要不冒称完整文件 SHA。只手动离线执行，无后台采集、状态持久化或 LLM 调用。

## 剩余现场证据

- N05/N06：当前游戏真实舰艇身份、原始与规范化四键、单位/基准/符号/范围、缺失/null/合法零、倒车/车钟与多机差异；逐舰型核对 datamine 静态配置和游戏改装状态。
- 仪表/探针失败与恢复、独立时效、实际死亡后无旧绑定、可信新生命后的重新采样；地图和 state 失败不得冒充仪表成功/失败。
- 原生 Electron 和实际海战观察；这些仍为“本轮跳过、未验收”，不改记通过。
- 数值卡需要真实语义证据足够后另定范围；真实输出、自动重生、舰员/弹药/舰体/进水等能力不随本合同开放。
