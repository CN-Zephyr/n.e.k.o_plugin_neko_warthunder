## 行为与边界

[纯投影](../adapters/ground_ammo_explanation.py) 复用 P1a 当前 vehicle 来源与 available 待发弹事实，允许摘要 partial；检查原始 count 类型、有限/非负整数及浏览器精确整数范围，并只读当前 processed.flags 的 ammo_low/ammo_empty 两个严格布尔标记。数字字符串、bool、非法容器或相矛盾的标记不被转成正常结论；没有查私有最大基线、重演 FSM 或估补弹时间。

| 状态 | 原卡解释 |
|---|---|
| source_unavailable | 来源不可用于解释，等待新数据；不沿用未知年龄的旧卡兼容路径 |
| count_unknown | 待发弹数未知，不能当零；包括超规格/非法值 |
| conflicting | 数量/标记非法或冲突，暂不判断 |
| zero_unconfirmed | 当前为 0，未取得一致耗尽标记；不是全车无弹 |
| empty_flagged | 当前为 0，数据层有耗尽标记；不是候选已确认或已经播报 |
| low_flagged | 当前正数，数据层有偏少标记；不能推容量或开火次数 |
| observed_count | 当前有数量、未取得一致偏少/耗尽标记；不是充足、已补满或已重武装 |

dashboard 仅增加 `ground_ammo_explanation: {status}`；其他域为 null。前端复用 [原陆战卡](../ui/panel.tsx) 的概览与诊断两处入口，保留原数值/岗位/LWS/活动页入口，并提示在活动页对照检测候选与输出。说明对象不包含数值副本、raw、flags 集合、玩家文本或历史原因。P1a/P1b 白名单/返回语义与模型提示未变，新模型调用和 token 均为 0。

离线、离场、阵亡、回放、来源过龄/未知年龄、未来时钟按原 P1a 规则收起解释；切域无投影，新生命不保留解释缓存。**载具来源独立 sample-life 仍 unverified**，本轮新生命回归证明不新增解释缓存，不冒充新采样生命绑定。补弹一帧清旗可显示未取得标记，但不能宣称 Detector 两次退出已完成。原低弹/打空/乘员/LWS、V2、VRS/海战输出闸完全保留。
