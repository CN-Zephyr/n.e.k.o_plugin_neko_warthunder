# 战雷猫娘副驾驶

`neko_warthunder` 是 N.E.K.O 的《战争雷霆》插件。它通过游戏的本地遥测接口显示仪表、地图和战果，并在用户开启战斗播报后，由当前角色提供简短提醒。插件仅读取游戏数据，无需注入游戏进程。

- **安装公开版** · 在 N.E.K.O 插件市场搜索「战雷猫娘副驾驶」，或从 [GitHub Releases](https://github.com/CN-Zephyr/n.e.k.o_plugin_neko_warthunder/releases) 下载 `.neko-plugin`。
- **查看版本差异** · 下文描述 **v0.1.4**。 [最新公开版本](https://github.com/CN-Zephyr/n.e.k.o_plugin_neko_warthunder/releases/latest) · [v0.1.2 发布记录](docs/release-v0.1.2.md) · [本轮验收记录](docs/release-v0.1.3.md)

## 安装和使用

需要支持 Hosted TSX UI 的 N.E.K.O 宿主，最低版本为 **v0.8.0**。插件支持 SDK `>=0.1.0,<0.3.0`，推荐 `>=0.1.0,<0.2.0`。面板以简体中文为主。

1. 在插件管理器中从市场安装，或导入下载的 `.neko-plugin`。按宿主提示批准并启动插件，再打开面板。
2. 在「诊断」页点「测试开口」试听当前角色。可以在进游戏前试听，也可以保持战斗播报关闭。
3. 进入对局、试驾、试飞或试航，在「概览」查看遥测状态。想听对局提醒时，点「开启战斗播报」。
4. 在面板填写游戏昵称，便于确认本人击毁和阵亡。需要跨重启恢复播报设置时，在「设置」勾选「记住战斗播报选择」。

首次启动默认只检测和记录（`dry_run`）。点「停止战斗播报」可返回只记录模式。需要立即暂停新的提醒时使用「急停」。在「活动」可以查看事件及其投递或拦截原因。

## 能力与边界

| 场景 | 面板与事件 | 播报边界 |
| --- | --- | --- |
| 空战 | 可用飞行仪表，超速、低空、过热等提醒 | 使用有效的仪表与场景证据。离地高度依赖有效 AGL，缺失时显示未知。 |
| 陆战 | 车速、转速、乘员、一级待发弹、部分模块损伤与激光告警 | 本人击毁、阵亡和激光告警可播报。乘员与弹药专项播报默认关闭，模块损伤只显示。 |
| 直升机 | 旋翼转速、离地高度、升降速度与涡环风险记录 | 进场与本人击毁可播报。涡环风险只记录。 |
| 海战 | 地图可见单位与本人战果。可用舰艇重生点标记海战场景 | 通用战果可播报。海战地图专项只记录。实测舰艇仪表未提供有效读数，本舰状态可能显示未知。 |

面板会标记缺失或过期的数据。自由文本专项只记录，识别为游戏录像回放时暂停战斗播报。 [现场记录与证据](docs/release-v0.1.3.md)

## 常见问题

- **能试听，但对局没声音** · 检查「概览」中是否开启了战斗播报。如果事件出现在「活动」里，可以查看它是否受静默窗口、安全暂停或事件类别限制。
- **看不到本人战果** · 在面板填写游戏内昵称。队名标签由插件在解析战果时处理。
- **海战有地图，没有舰速** · 两艘舰试航与一局常规海战的本舰仪表均未返回有效数据，地图和通用战果仍可使用。

## 开发与验证

游戏遥测来自 `127.0.0.1:8111`。内置数据层整理数据，插件业务通过 HTTP `127.0.0.1:8112` 读取，再由检测器、场景、仲裁和安全门决定是否经 Dispatcher 向宿主投递。启动适配器优先使用子进程，`embedded` 回退在插件进程内启动同一个 HTTP 服务。

身份、阵营颜色和录制开关通过 POST 修改，GET 用于读取。使用独立运行的旧版数据层时需同步升级。 [8112 接口文档](data_layer/data_process/后端接口文档.md)

在插件仓库根目录运行以下命令。发布联检与候选包构建需要相邻的 `N.E.K.O/` 宿主仓库，或通过 `--host-root` 指定宿主位置。

```powershell
uv run pytest -c "tests/pytest.ini" tests -q
uv run python "tools/release_readiness.py" --run --with-preflight
uv run python "tools/build_release_candidate.py"
```

GitHub Actions 配置了插件验证和 Python 覆盖率报告。候选包构建包含内容检查、payload 哈希校验和隔离安装。 [外部评审跟进与本地验证](docs/release-v0.1.3.md#外部评审跟进) · [样本回放](docs/样本回放-20260620.md) · [真机验收清单](docs/真机验证-checklist.md) · [实现计划](docs/实现计划-codex.md)
